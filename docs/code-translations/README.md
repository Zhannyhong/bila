# Code Translations

This folder contains Markdown companions for the main project Python files and tests.

Each companion is written as:

- direct pseudocode,
- plain English instead of programming syntax,
- close to the real implementation order,
- with only a small amount of context at the top.

The goal is to let you read what the code is doing without mentally parsing Python or MuJoCo details first.

Files covered:

- `main.py` -> `main.py.md`
- `shelf_scene.py` -> `shelf_scene.py.md`
- `insert_book.py` -> `insert_book.py.md`
- `perception.py` -> `perception.py.md`
- `view_scene.py` -> `view_scene.py.md`
- `xiaomi_vla_scenario.py` -> `xiaomi_vla_scenario.py.md`
